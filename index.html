Как использовал ИИ и проверял результат

Существенная задача для ИИ (пересказ): собрать на HTML, CSS и JavaScript портфолио по моим открытым проектам с выразительным дизайном, интерактивной картой, адаптивной вёрсткой и доступным списком кейсов.

Мои исправления по ходу работы: я отметил проблемы с читаемостью ранней версии, уточнил визуальное направление, исключил опыт работы в компаниях и выбрал запуск без npm и JSON-файлов. Технические правки по этим решениям внесены с помощью Codex.

Доработка с Claude Code: я попросил сделать плавные переходы и максимально развить игровой подход; конкретные механики «Экспедиции» — сигналы, маяки, радар, достижения и журнал — предложил и реализовал ИИ. Также с его помощью настроен деплой на GitHub Pages.

Проверка: сведения сверены с публичными репозиториями; протестированы адаптивность, управление, диалоги и автономный HTML. Подробности — в README.
