## Запуск и файлы

Откройте `index.html` в браузере. Для локального сервера можно выполнить `python3 -m http.server 8765`. Установка зависимостей для просмотра не нужна: готовый 3D-модуль уже лежит в `assets/experience.bundle.js`. `index.html` содержит структуру и тексты, `style.css` — оформление, `script.js` — карточки и навигацию, `experience.js` — исходный код 3D-сцены, `assets/` — локальные изображения, шрифт, готовый модуль и лицензии. После изменения сцены выполните `npm ci` и `npm run build:experience`. Команда `python3 build.py` обновляет `portfolio-standalone.html` со встроенными ресурсами и `portfolio.zip` для скачивания на телефон или компьютер.

Стили написаны по принципу **Mobile First**: базовые правила задают мобильную вёрстку, изменения для больших экранов находятся в `@media (min-width: 761px)` и `@media (min-width: 1101px)`. Сайт адаптирован для узких и широких экранов, клавиатурной навигации и `prefers-reduced-motion`.

## JavaScript

- Интерактивная 3D-карта проектов на Three.js: ровер движется клавишами WASD или стрелками, Shift ускоряет, Enter открывает ближайший кейс; на сенсорном экране есть кнопки. По станции можно также нажать мышью или выбрать её в списке. Камера следует за ровером, по дорогам идут импульсы; сцена приостанавливается вне экрана и учитывает `prefers-reduced-motion`.
- Диалоговые окна семи проектов с описанием и ссылкой на исходный код.
- Мобильное меню, копирование email и обновление года в подвале.

Для показа страницы внешние запросы не нужны. [Three.js](https://threejs.org/) включён в локальный модуль, условия использования — в `assets/three-LICENSE.txt`. Если WebGL недоступен, проекты открываются через карту и обычные карточки ниже.

## Использование ИИ и проверка

**Инструмент:** OpenAI Codex. **Задачи:** исследование публичных проектов, прототипирование и реализация дизайна, создание интерактивных элементов, проверка в браузере. Пароли, токены и закрытые данные в запросах не использовались. Публичный адрес почты и данные GitHub применены только для портфолио.

Один существенный запрос автора:

> Оформи более творческо сайт, поищи прикольные элементы на опенсорс площадках, поиграй с цветами, чтобы портфолио вызывало вау эффект, можешь делать стеком HTML/CSS/JS в разных файлах, если будет удобнее.

**Результат и проверка:** создана контрастная композиция с авторской интерактивной 3D-картой проектов и подробными кейсами ниже. После повторной сверки GitHub 24 сентября добавлены Job Ranker с графиком опубликованных NDCG@10 и инженерная работа F2F Bank Tests. Сведения о проектах сверены с публичными репозиториями. В браузере проверены адаптивность, управление 3D-сценой, открытие кейсов, меню, диалоги и автономный HTML. Проверка не заменяет оценку дизайна человеком и повторное обучение ML-моделей.

**Уточнения автора:** автор указал свой GitHub, попросил повысить читаемость и сделать дизайн более выразительным. Самостоятельные изменения кода автором пока не указаны; реализацию выполнил Codex. Это можно уточнить после собственных правок кода.

**Время выполнения автором:** уточняется. Не указано предположительное число часов, поскольку оно должно отражать личную работу автора.
