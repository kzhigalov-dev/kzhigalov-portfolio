Одностраничное портфолио Кирилла Жигалова, Junior Data Scientist / ML Engineer. На странице собраны реальные проекты, образование, навыки и контакты. Данные о проектах взяты из [публичного GitHub-профиля](https://github.com/kzhigalov-dev); ссылки на конкретные источники указаны в [SOURCES.md](SOURCES.md). ## Запуск и файлы

Откройте `index.html` в браузере. Для локального сервера можно выполнить `python3 -m http.server 8765`. Установка зависимостей для сайта не нужна. `index.html` содержит структуру и тексты, `style.css` — оформление, `script.js` — интерактивность, `assets/` — локальные изображения, шрифт, css-doodle и его лицензию. Команда `python3 build.py` обновляет `portfolio-standalone.html` со встроенными ресурсами и `portfolio.zip` для скачивания на телефон или компьютер.

Стили написаны по принципу **Mobile First**: базовые правила задают мобильную вёрстку, изменения для больших экранов находятся в `@media (min-width: 761px)` и `@media (min-width: 1101px)`. Сайт адаптирован для узких и широких экранов, клавиатурной навигации и `prefers-reduced-motion`.

## JavaScript

- Анимированное поле данных на Canvas: режимы «Точки» и «Сетка», пауза, остановка вне экрана и при снижении анимации в системе.
- Диалоговые окна шести проектов с описанием и ссылкой на исходный код.
- Мобильное меню, копирование email и обновление года в подвале.

Для показа базовой страницы внешние запросы не нужны. Библиотека [css-doodle](https://github.com/css-doodle/css-doodle) хранится локально; условия использования — в `assets/css-doodle-LICENSE.txt`.

## Использование ИИ и проверка

**Инструмент:** OpenAI Codex. **Задачи:** исследование публичных проектов, прототипирование и реализация дизайна, создание интерактивных элементов, проверка в браузере. Пароли, токены и закрытые данные в запросах не использовались. Публичный адрес почты и данные GitHub применены только для портфолио.

Один существенный запрос автора:

> Оформи более творческо сайт, поищи прикольные элементы на опенсорс площадках, поиграй с цветами, чтобы портфолио вызывало вау эффект, можешь делать стеком HTML/CSS/JS в разных файлах, если будет удобнее.

**Результат и проверка:** создана светлая композиция с контрастными кобальтовым и коралловым акцентами, графикой данных и кейсами. Сведения о проектах сверены с публичными репозиториями. В браузере проверены ширины 320, 390, 768, 1024 и 1440 px: нет горизонтальной прокрутки и ошибок JavaScript, работают меню, диалоги, переключатели и раскрытие описания работы с ИИ. Автономный HTML проверен без сетевых запросов. Проверка не заменяет оценку дизайна человеком и повторное обучение ML-моделей.

**Уточнения автора:** автор указал свой GitHub, попросил повысить читаемость и сделать дизайн более выразительным. Самостоятельные изменения кода автором пока не указаны; реализацию выполнил Codex. Это можно уточнить после собственных правок кода.

**Время выполнения автором:** уточняется. Не указано предположительное число часов, поскольку оно должно отражать личную работу автора.

История репозитория показывает отдельный исходный этап и последующие изменения под требования задания.
