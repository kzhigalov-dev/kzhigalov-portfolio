КИРИЛЛ ЖИГАЛОВ — DATA SCIENCE & ML ENGINEERING

Откройте index.html в браузере. Установка и сборка не нужны.
Рядом должны лежать style.css, script.js и папка assets.

portfolio-standalone.html — тот же полноценный сайт одним файлом:
CSS, JavaScript, шрифт и изображения встроены внутрь.
Дизайн един для компьютеров, планшетов и телефонов.

Особенности: интерактивная поверхность данных на Canvas и генеративный
узор css-doodle (все файлы включены локально),
локальный шрифт Manrope, реальные скриншоты ML-проектов, окна кейсов,
ссылки на репозитории, копирование почты, клавиатурная навигация.
Анимация учитывает prefers-reduced-motion и приостанавливается вне экрана.
Никаких внешних запросов для отображения сайта не требуется.

Данные и контакты: публичный GitHub kzhigalov-dev, проверено 11.09.2026.
Источники — SOURCES.md. Публикация на хостинге не выполнялась.
Метрики проектов приведены по README; обучение моделей повторно не запускалось.

Редактирование:
index.html — страницы, тексты и карточки;
script.js — подробности кейсов, взаимодействия и графика;
style.css — оформление;
assets — шрифт, библиотеки, лицензии и скриншоты.
После изменений: python3 build.py — обновляет ZIP и самостоятельный HTML.
