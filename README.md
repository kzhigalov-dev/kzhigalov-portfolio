# Кирилл Жигалов — портфолио

Одностраничное портфолио Кирилла Жигалова, ML Engineer / Data Scientist. На странице собраны проекты, образование, навыки и контакты. Данные о проектах взяты из [публичного GitHub-профиля](https://github.com/kzhigalov-dev); ссылки на конкретные источники указаны в [SOURCES.md](SOURCES.md). Метрики приведены по README проектов и не получены повторным обучением моделей.

## Запуск и файлы

Откройте `index.html` в браузере. Сайт состоит из обычных HTML, CSS и JavaScript-файлов: `index.html` содержит структуру и тексты, `style.css` — оформление, `script.js` — карточки, навигацию и плавные переходы, `game.js` — игровой слой «Экспедиция», `experience.js` — читаемый исходный код 3D-сцены. `assets/three.js` — локальная копия необходимой части Three.js; изображения, шрифт и лицензии также лежат в `assets/`. Для запуска и правок не нужны npm, JSON-файлы или сборка. Готовый архив и автономный HTML-файл доступны в [релизах](https://github.com/kzhigalov-dev/kzhigalov-portfolio/releases); после правок их пересобирает `python3 tools/build_standalone.py` (нужна только стандартная библиотека Python).

Стили написаны по принципу **Mobile First**: базовые правила задают мобильную вёрстку, основные переходы к широким экранам находятся в `@media (min-width: 761px)` и `@media (min-width: 1101px)`; для большой сцены есть дополнительная настройка от 1200 px. Сайт адаптирован для узких и широких экранов, клавиатурной навигации и `prefers-reduced-motion`.

Визуальная система строится на четырёх ролях цвета: тёплый светлый фон для чтения, тёмно-синяя сцена для исследования проектов, кобальтовый для ссылок и результатов, коралловый для основных действий. Маршрутные линии, редкие звёзды и созвездия связывают 3D-карту с архивом кейсов, профилем и контактами. Manrope используется для крупных заголовков и текста, моноширинный шрифт — для технических подписей. Кейсы связаны единой сеткой, типографической иерархией и повторяемыми состояниями кнопок; на узком экране они выстраиваются в одну колонку.

## Деплой на GitHub Pages

Сайт публикуется GitHub Pages из ветки `main`, корень репозитория (Settings → Pages → Deploy from a branch). Сборка не нужна: после `git push origin main` GitHub сам выкладывает текущие файлы, обычно за минуту. Файл `.nojekyll` отключает обработку Jekyll, поэтому страницы отдаются как есть. Все пути относительные, так что сайт работает и по адресу `/kzhigalov-portfolio/`, и локально. При изменении `style.css` или скриптов стоит поднять версию в `?v=` в `index.html`, чтобы браузеры не держали старую копию. Статус публикации виден во вкладке Actions (`pages build and deployment`).

## JavaScript

- Интерактивная 3D-карта проектов на Three.js: ровер с поворачивающимися колёсами и камерой слежения движется клавишами WASD или стрелками. Shift ускоряет, пробел тормозит, R возвращает на старт; на сенсорном экране есть кнопки движения, выбора проекта и возврата. Enter у ближайшей станции, нажатие на неё мышью или выбор в списке открывают краткое досье с задачей, подходом и опубликованным результатом. Камера приближается к проекту, «Далее» переключает станции, «Открыть кейс» показывает полное описание, а Escape возвращает к карте. При открытом досье стрелки влево и вправо также переключают проекты. Сцена приостанавливается вне экрана и учитывает `prefers-reduced-motion`.
- Сигнальный курсор на всём лендинге: орбитальный прицел меняет контраст на светлом и тёмном фоне, раскрывается над действиями, а над станцией принимает её цвет. Эффект отключён на сенсорных экранах и при `prefers-reduced-motion`.
- Игровой слой «Экспедиция»: станции засчитываются при открытии досье на карте или кейса в архиве, на дорогах между станциями лежат 12 сигналов данных, которые ровер собирает при проезде. Исследованные станции получают световой маяк и отметку на табличке, в архиве и в списке карты. В режиме езды видны скорость, счётчики и радар; станции твёрдые, ровер объезжает их. Десять достижений, включая секретное (Konami-код включает радужный след кометы), появляются во всплывающих уведомлениях. Журнал экспедиции открывается из шапки или клавишей J: прогресс, станции с быстрым перелётом к каждой, достижения, пройденный путь и сброс. Прогресс хранится в `localStorage` этого браузера; все кейсы доступны и без игры.
- Плавные переходы: секции и созвездия проявляются при прокрутке каскадом, заголовок первого экрана перетекает в компактный HUD через View Transitions, окна кейсов и журнала выезжают и гаснут, досье плавно закрывается и сменяется, камера при загрузке опускается на карту, тонкая линия у верхнего края показывает пройденную часть страницы. При `prefers-reduced-motion` анимации отключены.
- Диалоговые окна семи проектов с описанием и ссылкой на исходный код.
- Мобильное меню, копирование email и обновление года в подвале.

Для показа страницы внешние запросы не нужны. [Three.js](https://threejs.org/) хранится локально как `assets/three.js`, условия использования — в `assets/three-LICENSE.txt`. Если WebGL недоступен, проекты открываются через карту и обычные карточки ниже.

## Как я использовал ИИ

Я взял собственный [GitHub-профиль](https://github.com/kzhigalov-dev) как источник материалов, определил направление портфолио и оценивал промежуточные версии. OpenAI Codex помог исследовать открытые репозитории, собрать страницу и интерактивную сцену, а также проверить результат в браузере. Закрытые данные, пароли и токены для содержания сайта не использовались.

**Один существенный запрос к ИИ (пересказ, без дословной цитаты):** разработать выразительное одностраничное портфолио на HTML, CSS и JavaScript на основе моих реальных проектов; сделать понятные кейсы, интерактивную 3D-карту с управлением, адаптивную вёрстку и удобный способ открыть любой проект без 3D.

**Мои решения и исправления по ходу работы:** после просмотра ранних версий я указал на недостаточную читаемость и попросил усилить дизайн; выбрал интерактивное направление, исключил сведения об опыте работы в компаниях и настоял на запуске без npm и JSON-файлов. Эти замечания определили финальную структуру и внешний вид. Технические правки по моим решениям внесены с помощью Codex.

**Как проверялся результат:** проекты и опубликованные метрики сопоставлены с исходными репозиториями; в браузере проверены ширины 320, 390, 768, 1024 и 1440 px, управление сценой, открытие кейсов, меню, диалоги и автономный HTML. Проверка не означает повторное обучение ML-моделей. Сайт и исходники доступны по ссылкам выше.

**Время моей работы над заданием:** 3 часа.

История коммитов показывает этапы разработки и исправлений.
